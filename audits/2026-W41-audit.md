# Oh Betty Jaletti: Weekly UX/UI + SEO/AEO/GEO Audit, 2026-W41 (Oct 9, 2026)

**Scope limits this week:** the live storefront (ohbettyjaletti.com) could not be fetched from the routine sandbox (DNS/proxy block), so this audit is based on Shopify Admin data (products, collections, pages, SEO fields) plus research. Theme code, rendered HTML, robots.txt, sitemap, schema output and Core Web Vitals are **unverified**. See item D-1.
**Research quality note:** most search results were vendor blogs. Stats are directional; only Baymard is a primary source.

## A. Critical (fix first)
| ID | Issue | Evidence | Why it matters | Recommended change |
|---|---|---|---|---|
| A-1 | **All 5 products are DRAFT, unpublished, 0 inventory** | Shopify: status DRAFT, `publishedAt` null, inventory 0 on every SKU | Collection copy says "Open September 29, retired December 31". Today is Oct 9. If the edition is meant to be live, nothing can be bought or indexed. | Confirm intent. If live: publish products, set inventory, assign to the Online Store channel. If not yet launching: update collection copy dates. |
| A-2 | **No product media** | `mediaCount` = 0 on all products | No images = no Google Shopping/Merchant eligibility, no rich results, major conversion drop; AI shopping surfaces need images. | Add 4+ images per product (hero, scale/in-hand, detail, packaging), descriptive alt text. |
| A-3 | **Date/state contradictions across pages** | Pages exist for "The Waitlist", "Consider It Sealed", "The Doors Have Closed" alongside an open-edition collection | Visitors and crawlers may hit conflicting states (open vs closed). | Map the edition lifecycle (waitlist, open, sealed, closed) and confirm only the correct page is linked/indexed at any time. |

## B. Necessary (high impact, low risk)
| ID | Issue | Recommended change |
|---|---|---|
| B-1 | Collection SEO title has leading whitespace and uses an em dash: `"  The Reading Hour — Linen Covers & Keepsakes..."`. Title says "Linen Covers" but products are a book sleeve, notebook, candle, glass. | Trim, rewrite to match the real products, e.g. "The First Edition: Reading Hour Objects | Oh Betty Jaletti". |
| B-2 | Product SEO titles are good but long (likely over 60 chars, truncated in SERPs). | Keep brand-first keyword in first ~55 chars. |
| B-3 | Product descriptions are brand-voice rich but **lack extractable facts** (dimensions, materials, wax weight/burn time, glass capacity, care, shipping, what's in the box). AI engines and shoppers quote specifics. | Add a short "Details" block (bulleted spec list) under each description. Keep voice in the narrative above it. |
| B-4 | Single-variant, scarcity-led products with no stated edition size. | State edition size/numbering ("No. X of N") where true. Scarcity claims need to be accurate. |
| B-5 | Collection "Home page" (`frontpage`) has no SEO fields. | Low priority; ensure homepage title/meta set in Online Store preferences. |
