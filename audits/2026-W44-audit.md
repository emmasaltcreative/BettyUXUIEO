# Oh Betty Jaletti: Weekly UX/UI + SEO/AEO/GEO Audit, 2026-W44 (Nov 1, 2026)

**What changed since W41:** the live site (ohbettyjaletti.com) is now reachable from the routine, so this is the first audit with rendered-page evidence (home, 2 collections, 3 products, robots.txt, sitemap, llms.txt). Three products went live (Oct 19-23) and a second collection, "In Her Purse" (Edition I), exists.
**Still unverified:** Core Web Vitals (PageSpeed API rate-limited, 429), Search Console/Bing status, checkout (Shop Pay, guest checkout, shipping shown early), and Google's own structured-data docs (developers.google.com is outside this session's allowed network domains).
**Research quality:** web search returned mostly vendor blogs; stats are directional. Primary: Shopify UCP page only. Two unverified claims were deliberately not used (a "20.8% low-stock lift" attributed to Baymard; a "2.0s LCP target").

## Wins (keep)
- Agent-readiness is ahead of most stores: `llms.txt`, `agents.md`, UCP discovery (`/.well-known/ucp`) and an MCP endpoint are live; robots.txt allows all crawlers.
- Product pages have Product + BreadcrumbList JSON-LD with brand, price, image, SKU; the homepage has Organization (with `alternateName: Maison Betty Jaletti`, which resolves most of the naming conflict) + WebSite/SearchAction.
- Preorder copy is unusually clear: price, "charged today", "ships by 15 December 2026", and a no-letter-required full refund promise. Canonicals present; pages are 70-90 KB and respond in ~0.3-0.6s.
